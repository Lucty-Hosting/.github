# 💜 Code de conduite

LUCTY est une association ouverte à toutes et à tous. Pour que nos espaces
(dépôts, Discord, échanges) restent agréables, nous attendons de chacun·e :

- du **respect** et de la bienveillance, quels que soient l'âge, l'origine,
  le genre, le niveau technique ou les opinions de chacun·e ;
- des **critiques constructives**, qui portent sur le code et pas sur la personne ;
- **aucun harcèlement**, propos discriminants, insultes ou contenu inapproprié.

## En cas de problème

Signalez tout comportement inacceptable à **contact@lucty.fr**.
Chaque signalement sera traité de manière confidentielle.
L'équipe peut avertir, exclure temporairement ou définitivement toute personne
qui ne respecte pas ce code.
