# 🔒 Politique de sécurité

La sécurité des projets que nous hébergeons est notre priorité.

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans l'un de nos services ou dépôts,
**merci de ne pas ouvrir d'issue publique**.

Écrivez-nous plutôt à **contact@lucty.fr** avec :

- une description de la vulnérabilité ;
- les étapes pour la reproduire ;
- l'impact potentiel selon vous.

Nous accusons réception sous **72 heures** et vous tenons informé(e) de la correction.
Merci de nous laisser le temps de corriger avant toute divulgation publique.

Merci d'aider LUCTY à rester sûr pour tout le monde 💜
