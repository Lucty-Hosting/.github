# 🤝 Contribuer aux projets LUCTY

Merci de vouloir contribuer ! Voici comment faire :

1. **Ouvrez une issue** pour discuter de votre idée ou du bug avant de coder.
2. **Forkez** le dépôt et créez une branche : `git checkout -b feature/ma-fonctionnalite`
3. **Commitez** avec des messages clairs : `fix: corrige le redémarrage du bot`
4. **Ouvrez une Pull Request** en expliquant ce que vous avez changé et pourquoi.

Un membre de l'équipe relira votre PR dès que possible.

Une question ? Rejoignez notre [communauté Discord](LIEN_DISCORD) ou écrivez à contact@lucty.fr.
